A probabilistic database with a pseudo-RESTful API, tailored for [one specific purpose](https://ekunazanu.foo/lab/free-speech). Lightweight and extremely efficient. Refer [here](https://ekunazanu.foo/log/4-pb-mb-db/) for more details.

Written in Go, using only standard libraries — simply run `go run .` in the project directory to start serving and listening for requests at `localhost:8080`.
